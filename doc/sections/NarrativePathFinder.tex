\subsubsection{Path A}

In this path, the narrative begins at the start node and then branches at the first conditional node B and then branches at the conditional node C. Then the path loops back to the conditional node B. At this point, the path can be terminated because there are no new decisions that can be made that will lead out of this loop. The option to take the other branches will be addressed in the other branches that are taken in the path finding algorithm from this same node.

\subsubsection{Path B and C}

In path B, the design makes two decisions and arrives at the end node. THe narrative path is:

Path B:
Start -> B -> C -> E -> end

Path C:
Start -> B -> F -> G -> end

Since all the nodes have unambiguous meaning and invariants, the semantic validity of the narrative can be estabished.
